Instructions:
Type name, then press enter to add the players to a list. You can remove the players to fix misspellings or people who have changed their mind
Click the start tournmaent button. This will also save the created tournament.
To the left will be a list of people, to the right will be the matches, always 5 matches wide.
On the list of people, you will be able to see how many wins, losses, byes, and a place to remove people from the tournament. (Eliminated people will be removed from the list)
On the matches you will be able to choose a winner and change the winner. (You can only change the winner in an active round)
The button for moving on will only be shown when every match has a selected winner, so if someone leaves you have to remove them.
Every time the button is clicked to generate a new match, the matches are decided randomly, however playing the same person more than once is limited to tie breakers and forced repeats.
Every time the button is clicked the tournament will be saved for reloading in case of closing the page or hitting refresh
Matches can be repeated for first and second place, ie. somone is 6/0 with 1 bye, someone else is 6/1 with no bye and the first player wins, neither have two losses and they would have to do a rematch tie breaker to have been double eliminated.


The website should be fully functional for creating fair pool tournaments in a presentable manner, while allowing the host to change winners during rounds, add players, and remove players during rounds.
The byes are completely random, if you add a player any match not marked with a win can be randomized to create a fair bye.
If you remove a player with an even number of people the player in a match with the leaver recieves the bye, if there is an odd number of players the player will be matched with the person that presently has the bye.
During each round you can change which winner, when you start a new round the current winners can not be changed. It also saves the tournament at this point so you can refresh or close the website, then click load to restart at the same spot.
